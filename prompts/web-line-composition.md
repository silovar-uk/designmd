# Webページの行と文章を設計するプロンプト

以下を、通常のDesignMDと併用する。

```text
以下の制作ガイドを必須要件として参照してください。
https://raw.githubusercontent.com/silovar-uk/designmd/main/DESIGN.md
https://raw.githubusercontent.com/silovar-uk/designmd/main/docs/web-line-composition.md

今回の依頼：
（依頼内容）

Webの一行は固定された部品ではなく、画面幅、文字倍率、書体、ブラウザによって変化するものとして扱ってください。
紙の外見を再現するのではなく、意味単位、行幅、視線、情報の優先順位に対する編集密度を移植してください。

実装前に、各主要見出しについて次を整理してください。
- 見出しの役割
- 最大行数
- 同じ行に置きたい意味のまとまり
- 分割禁止語
- 推奨する折り返し候補
- スマホで短縮可能な表現

実装ルール：
- 固定の<br>は原則使わない
- 見出しはtext-wrap: balanceを漸進適用する
- 本文はtext-wrap: pretty、line-break: strictを基礎にする
- 本文幅は全角28〜36字程度を目安にする
- nowrapは人名、日付、数字＋単位、短いタグなど分割不能な単位だけに使う
- word-break: break-allを本文全体へ使わない
- 長いURLや識別子だけoverflow-wrap: anywhereで救済する
- ボタンが2行になる場合は、先に文言と配置を見直す
- 320、375、768、1024、1440pxと200％文字拡大で確認する

完成後、次を報告してください。
1. 固定した意味単位
2. 流動させた行末
3. 使用した固定改行と、その必要理由
4. 幅を変えた時に最も崩れやすかった箇所
5. PC・スマホで変えた文言または構図
6. 長いURL、固有名詞、数字＋単位の処理
```
