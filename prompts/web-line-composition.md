# Webページの行と文章を設計するプロンプト

以下を、通常のDesignMDと併用する。

```text
以下の制作ガイドを必須要件として参照してください。
https://raw.githubusercontent.com/silovar-uk/designmd/main/DESIGN.md
https://raw.githubusercontent.com/silovar-uk/designmd/main/docs/web-line-composition.md

今回の依頼：
（依頼内容）

日本語の改行では「規則上、改行できる場所」と「読み手にとって、そこで改行したい場所」を分けてください。
Webの一行は固定された部品ではなく、画面幅、文字倍率、書体、ブラウザによって変化するものとして扱ってください。
紙の外見を再現するのではなく、禁則、意味単位、視線、情報の優先順位、行長を調整する判断方法を移植してください。

主要な表示文字について、次の5層を順に確認してください。
1. 規則：禁則や文字単位を守る
2. 語：短い見出しでは固有名詞、外来語、複合語を不自然に割らない
3. 意味：文節・フレーズのまとまりを優先する
4. リズム：最終行の短さ、一語孤立、短い行の連続を確認する
5. 適応：PCの行末をスマートフォンへ固定しない

実装前に、各主要見出しについて次を整理してください。
- 見出しの役割
- 最大行数
- 意味のまとまり
- 分割を避けたい語
- 推奨する折り返し候補
- 固定改行の必要性。原則不要
- 短い表示文字で許容する最小文字サイズ
- スマホで短縮可能な表現

実装ルール：
- 固定の<br>は意味上の理由がある例外だけにする
- 見出しはtext-wrap: balanceを漸進適用する
- 対応環境ではword-break: auto-phraseを漸進適用する
- 本文はline-break: strict、word-break: normalを基礎にする
- word-break: break-allやoverflow-wrap: anywhereを本文全体へ使わない
- 長いURLや識別子だけoverflow-wrap: anywhereで局所救済する
- nowrapは人名、日付、数字＋単位、短いタグなど短い分割不能単位だけに使う
- 編集上望ましい任意の折り返し候補には、必要に応じて<wbr>を検討する
- ボタンが2行になる場合は、先に文言と配置を見直す

収まらない場合は、次の順で検討してください。
意味 → 文言 → 幅・余白・配置 → 折り返し候補 → 字間 → 短い表示文字のサイズ → 行数追加

本文は収めるために縮小しないでください。
ヒーロー見出しや短いキャッチコピーで文字サイズを調整する場合は、最小サイズを先に決め、下限を超えたら縮小を続けず一行増やしてください。

320、375、768、1024、1440pxと200％文字拡大で確認してください。

完成後、次を報告してください。
1. 固定した意味単位
2. 流動させた行末
3. 使用した固定改行と、その必要理由
4. 使用したnowrap、wbr、長トークン救済と、その対象
5. 文字サイズを調整した箇所、下限、理由
6. 幅を変えた時に最も崩れやすかった箇所
7. auto-phrase非対応環境でのフォールバック
```
