For AI

正典と事例を、
同じ強さで読ませない。

AIには、人間向けの地図を歩かせず、用途別Context Packと機械可読manifestを渡します。stableな原則・ガイドを先に読み、experimentalとcaseは状態を明示して扱います。

機械可読入口

  • llms.txt
  • ai-manifest.json
  • knowledge-map.json

用途別Pack

  • 文章制作
  • スライド制作
  • Web・アプリ
  • AIとの協働
  • レビュー
  • 運用・回復

読む優先順位

  1. stable principle
  2. stable guide / pattern
  3. experimental
  4. case
  5. essay / reference

必ず確認する項目

  • status
  • use_when
  • avoid_when
  • relations
  • 更新日と正典URL
以下のdesignmd Context Packを必須要件として参照してください。
（用途に合うPack URL）

caseは普遍的な規範ではなく、適用例として扱ってください。
status、use_when、avoid_whenを確認し、今回の条件に合わない規則は機械的に適用しないでください。
